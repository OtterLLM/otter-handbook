This is a **sample note**, used only to demonstrate the layout. Delete it when you write real content.

We suggest writing an observation in four parts:

1. **Setup**: model size, data, steps trained, and which hyperparameters differ from the defaults.
2. **Phenomenon**: one sentence on what you saw.
3. **Evidence**: curves, tables, or the command that reproduces it.
4. **Possible explanation**: write a guess as a guess, and say which experiment is still missing to confirm it.

:::obs[Write the title as a falsifiable sentence]
For example, "After changing X from a to b, validation loss is lower before step N and on par afterward", rather than "X matters".
:::
